# GREENS reviewer guide

For the ISCAS headline claim set, start with the [artifact overview](../experiments/iscas/README.md), [exact reproduction instructions](../experiments/iscas/reproduction.md), and [claim-to-evidence index](../experiments/iscas/claims.md).

```bash
python scripts/reproduce_iscas.py
python scripts/reproduce_iscas.py --check
```

The scientific path runs from declared service and implementation, through route/setup/hold qualification, to matched operation energy and conditional workload preference. [Public scientific evidence](../experiments/iscas/evidence/README.md) supplies human-readable conditions and tables. Integrity checks run automatically; no author filesystem or development-history knowledge is needed.

For a broader software audit, use `make reviewer-smoke`, then the full software/native contract in [CONTRIBUTING.md](../CONTRIBUTING.md). The short ISCAS path does not establish physical FIT/Qcrit, complete macro energy, silicon measurements, signoff, or lifecycle carbon. [Limitations](limitations.md)
