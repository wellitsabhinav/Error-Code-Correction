# GREENS documentation

This suite is reconstructed from executable source, schemas and registry manifests, tests, freshly regenerated evaluation artifacts, and only then historical prose. Quantitative claims link to machine-readable evidence; missing physical values remain null.

## Recommended paths

**New user:** [Getting Started](GETTING_STARTED.md) → [Concepts and Identities](CONCEPTS_AND_IDENTITIES.md) → [ECC Catalogue](ECC_CATALOGUE.md) → [Results](RESULTS_AND_INTERPRETATION.md).

**Artifact reviewer:** [Reproducibility](REPRODUCIBILITY.md) → [Verification Methodology](VERIFICATION_METHODOLOGY.md) → [Fair Comparison](FAIR_COMPARISON.md) → [Claim Ledger](CLAIM_LEDGER.md).

**ECC/RTL developer:** [System Architecture](SYSTEM_ARCHITECTURE.md) → [Extending with a New ECC](EXTENDING_WITH_A_NEW_ECC.md) → [Characterization and Evidence](CHARACTERIZATION_AND_EVIDENCE.md).

**Thesis reader:** [consolidated technical guide](../GREEN_ECC_PHY_TECHNICAL_GUIDE.md), with figures indexed in [Figure Index](FIGURE_INDEX.md).
