# GREENS generated ISCAS reviewer derivations

These are small, intentionally tracked derivations of frozen campaign evidence. They are not new physical measurements or copies of raw datasets.

Regenerate from the root with `python scripts/reproduce_iscas.py --output experiments/iscas/generated`. Verify numerical outputs with `python scripts/reproduce_iscas.py --check`. [Instructions](../reproduction.md) and [claim map](../claims.md) describe every output.

The figure is a new repository visualization of admitted operation deltas and a clean-read/write workload slice; original manuscript figure numbers/layout are not asserted. SVG appearance can vary with Matplotlib version; CSV/JSON are the numerical comparison contract.
