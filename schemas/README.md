# Validation schemas

`citation-1.2.0.schema.json` is the unmodified Citation File Format 1.2.0 schema from the [Citation File Format project](https://github.com/citation-file-format/citation-file-format/blob/main/schema.json), distributed under [Creative Commons Attribution 4.0](https://github.com/citation-file-format/citation-file-format/blob/main/LICENSE). Attribution belongs to that project's contributors. This third-party schema retains its upstream license; GREENS' own code uses the root MIT license.

The schema is vendored so citation validation does not depend on a network request. Other schemas in this directory define GREENS' existing data contracts.
