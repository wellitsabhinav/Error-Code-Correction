# Recovered local GREENS provenance

These files were absent from the public main-branch history at the cleanup base and recovered from the named WSL distributions. Their original paths, sizes, SHA256 values, purposes, and decisions are recorded in `../LOCAL_TO_GITHUB_AUDIT.csv`. Duplicate copies are imported once.

This is historical evidence and source recovery, not a replacement implementation or a new canonical result population. Gate04 orchestration/postprocessing/amendments, seed-control scripts, OpenRAM failure/reproduction helpers and patch material, and run/provenance summaries retain their original bytes and assumptions. Absolute paths in these records describe past runs. Existing public CLIs and current campaign qualification remain authoritative.

Restoring an entire campaign also needs its verified external archive, recorded tool/PDK environment, and the original directory topology. Copied helpers are not automatically portable or tested as a new workflow. Upstream-derived tool scripts/patches retain their upstream licensing; this recovery does not relicense dependencies.
